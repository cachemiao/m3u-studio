# 配置与台标 ZIP 格式 v1

ZIP 包含 `manifest.json`（format=`m3u-studio-backup`、version=1）、`config.json` 和 `logos/*.png`。配置使用现有 validate 规则，包含当前应用到工作区的草稿；账号、会话密钥、历史数据库及外部图片内容不导出。图库独立导出的 ZIP 只有 logos 目录，不能作为配置备份恢复。

恢复先完整校验，再增加图库文件，最后由浏览器将返回的配置应用为本地草稿。不写正式 state/history，不自动发布；已有图片不覆盖、不删除。不同内容的同名文件使用稳定后缀另存并改写恢复配置引用，重复恢复可复用相同图片。缺失的本地图片引用只报告数量，不删除用户配置。

写入异常会清理本次创建的文件。进程/设备在写入时强行中断可能留下未使用的新图片，但不会覆盖原图或正式配置；这不是数据库与文件系统的跨资源事务。浏览器在响应丢失时可重新恢复，已存在的相同图片会复用。工作区发生变化时不应用迟到的恢复结果。

只读取白名单路径，不使用 extract/extractall；拒绝重复名称（含大小写/规范化冲突）、软链接、加密或不支持的压缩格式；限制压缩包、解压总量、单文件大小和图片解码像素。所有图片和配置在写入前校验；较大 PNG 会按现有图库尺寸归一化。限制为 ZIP 64MiB、展开 128MiB、最多 5000 张台标，JSON/单图片 8MiB。

接口沿用登录与请求头校验；每个 worker 最多一个档案操作。导出时持有 SQLite 写事务，与现有上传/删除操作串行化，防止生成混合时点的图库。本轮不增加数据库表或修改 schema version。部署反向代理的请求大小限制也需要允许所需的备份大小，否则请求会在到达应用前被拒绝。

回归覆盖：草稿导出、整个图库导出、恢复不发布/不改账号、同名重映射及重复恢复、隐藏台标排除、危险路径、无效图片、无效配置、未来格式、解压限制、写入失败回撤、认证/跨站保护和缺失引用报告；浏览器验证 ZIP/JSON 恢复、下载、新入口以及移动端边界。
