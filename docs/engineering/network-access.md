# 服务端请求目标策略（升级行为变化）

远程列表导入和源检测默认只连接公网单播地址。管理账号登录不再意味着能够连接任意容器可达的服务。

合法内网 IPTV 通过独立的允许范围启用：

```yaml
environment:
  IMPORT_ALLOWED_NETWORKS: "192.168.1.30/32"
  IMPORT_ALLOWED_PORTS: "80,8080"
  SOURCE_ALLOWED_NETWORKS: "192.168.1.20/32,fd12:3456::/64"
  SOURCE_ALLOWED_PORTS: "3224,5140,80,443"
```

这里的 IP 仅是填写格式示例，应替换为自己的订阅/转发服务器。NETWORKS 是额外允许的非公网目标；公网默认仍允许。PORTS 留空允许合法端口，填写后同时约束公网与允许的内网目标。优先使用单主机 `/32`、`/128`，不要为了省事开放整个家庭网段。两个功能的允许范围互不继承。

配置在容器环境中生效，修改后重建容器。Compose 文件已支持从同名环境变量或 `.env` 传入；不创建 `.env` 时仍按安全默认值运行。

链路本地、组播、未指定地址、已列明的元数据端点和 IPv6 转换地址不因宽泛 CIDR 而放开。回环只接受显式单主机例外，普通网段或 `/0` 不会放开它。服务端会验证所有解析结果；混合了未允许地址的域名整体拒绝。连接直接使用已验证 IP，保留原始 HTTPS 主机名进行证书校验，每次重定向重新检查。

这两项用户提供的 URL 请求不自动使用 HTTP_PROXY / HTTPS_PROXY，避免代理在另一侧解析并连接未经验证的目标。需要代理的网络部署暂不支持这两项代理转发，不应通过关闭校验来迁就代理；版本检查使用独立传输，不受此项调整影响。

导入限制整体 10 秒、约 8MB 和最多 3 次重定向；源检测保留整体 5 秒、有限读取和并发限制。网络策略不是流媒体解码器，也不保证源持续可播放。

升级时若原有内网导入/检测变为策略拒绝，请先核对允许范围，不能直接认为源失效。源检测会显示“策略限制”；不要把它当成普通超时。策略拒绝不返回解析出的内网 IP。

测试覆盖特殊 IPv4/IPv6、映射地址、独立允许范围、端口、混合 DNS、固定连接目标和指向元数据地址的重定向。它不是对所有网络环境的穷尽安全证明；部署仍应使用可信访问入口及必要的出站防火墙。
