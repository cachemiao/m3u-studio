# M3U Studio 使用指南

Docker 自托管的 IPTV 频道编辑器，Web 后台、Logo、M3U 和 TXT 共用固定 18080 端口。Flask + Gunicorn + SQLite，前端无需 Node 构建和外部 CDN。

## 语言与外观主题

- 点击顶部语言图标选择简体中文 / English；点击主题图标选择浅色、深色或跟随系统。
- 默认跟随系统，在当前浏览器记住选择；同源标签页同步偏好，刷新前提前应用主题，减少亮色闪烁。
- 登录页、频道卡片、编辑弹窗、台标库和原生表单控件统一配色。主题偏好独立于频道配置，无需保存并发布。

## v0.3.2 台标库

- 点击频道台标，从左到右为 **台标库 → 上传 → 链接**。
- 台标库统一管理本地上传图片，支持搜索、选择和自动匹配；不再提供外置 GitHub 图库。
- 上传按图片原文件名入库，JPEG/WebP 转为同名 PNG。建议使用频道名称命名，方便匹配；中文、加号和括号受支持。
- 遇到同名台标弹出 **替换 / 停止**。替换保留图片地址，立即更新使用该图片的频道；停止保留原图。在批量上传中，停止会终止后续上传，已成功上传的图片保留。
- 设置 → 台标库管理：查看、搜索、批量上传、替换、删除。删除前提示已发布频道及当前草稿中的使用情况，确认后生效；频道地址不自动清空。
- 直接输入图片链接只绑定频道，不加入台标库。旧版已绑定的外置图片链接继续保留，图库管理入口移除。
- 台标库变更立即保存，频道绑定仍须保存并发布。图片文件和删除记录不随草稿撤销或发布历史恢复，请完整备份 `data/`。

## 其他编辑功能

- **批量编辑**：勾选频道或选择当前筛选结果，统一修改分组、频道 EPG、FCC，或替换直播/回放地址中的文字。修改前通过后端完整校验，预览后才应用到草稿；保存发布后生效。留空 EPG/FCC 表示清除，仅在勾选对应修改项时生效。
- **台标搜索与匹配**：单频道台标库支持搜索、数字自然排序和推荐项；工具栏“匹配台标”处理已选频道，无选择时处理当前筛选结果。默认保留已有台标，勾选后可替换。只自动应用名称或 EPG ID 唯一匹配的台标，保留 CCTV5+ 与 4K 的区别，支持常见台标简称；先预览再应用。
- **撤销 / 重做**：支持当前页面的频道编辑、批量修改、排序、分组/列表修改、导入、JSON 恢复及历史恢复。最多 50 步，并按内存限制裁剪。按钮和 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z 均可使用；输入框内保留原生文本撤销。刷新页面会清空编辑撤销栈；保存发布后撤销仅产生新草稿，不会立即修改订阅。
- **发布历史**：“设置 → 查看历史”显示最近 30 份发布前配置。配置和快照在 SQLite 同一事务内保存，兼容升级前的 JSON 备份。恢复到草稿后可检查、撤销或保存发布；账号、台标图片文件和当前订阅主机地址不回退。历史中的本地台标引用仍依赖 data/logo 中的图片。
- **订阅一键复制**：合并与独立列表的 M3U/TXT 地址均可复制；独立列表显示草稿中的频道数量。HTTP 内网使用兼容复制方式，受浏览器限制时可手动选中地址复制。

列表切换会清空频道选择；切换分组或搜索会保留选择，批量编辑对所有已选频道生效，包括筛选后隐藏的已选项。台标自动匹配不会联网检测播放源。

## 全新安装

解压至 `/data/iptv-manager`，执行：

```sh
cd /data/iptv-manager
sh setup.sh
docker compose up -d --build
```

打开 `http://设备IP:18080`，**首次直接在网页设置用户名和密码**（至少 8 个字符），无需配置 `.env`、无需手填服务器 IP。账号哈希和登录密钥保存在 data 数据卷里，重新构建镜像不会重置账号。后续用网页登录，也可在“设置 → 账号设置”修改用户名或密码。

订阅和本地 Logo 的完整地址自动使用浏览器/播放器实际访问的主机地址。通过 `http://设备IP:18080` 访问时，生成该地址；通过另一内网 IP 或域名访问时自动使用对应地址，不使用 Docker 内部 IP。容器统一发布 18080 端口，客户端需能访问此设备。

`setup.sh` 在 root 下为 data 设置容器 UID 10001 的读写权限。非 root 部署时，运行 `sudo chown -R 10001:10001 data`。首次构建需联网获取 Python 基础镜像与依赖。ARM64/aarch64、AMD64 为目标平台。

## 从旧版本升级

公开版不再包含台标图片。替换旧源码前请先执行下述迁移步骤。

### 从内置台标版本迁移

升级 v0.3.3 及更早版本前，先备份数据，并把旧版台标复制到本地图库。在旧项目目录执行：

```sh
mkdir -p data/logo
find app/builtin -type f -name '*.png' -exec cp -n {} data/logo/ \;
```

复制不会覆盖已上传的同名台标，数据库中已删除的台标仍保持隐藏。完成后再替换源码和重建容器。公开版发布包不含台标图片，旧台标应由使用者自行保留。



现有频道、分组、Logo、SQLite 配置和 `.env` 均保留。旧 `.env` 中的管理账号会一次性迁移到新网页登录；迁移后网页账号优先，不再被 `.env` 覆盖。旧 PUBLIC_BASE_URL 设置不再使用，地址改为自动识别。

将更新包上传至 `/tmp/`，在服务器执行（包的文件名以你实际上传的为准）：

```sh
cd /data/iptv-manager
docker compose stop
backup_file="/data/iptv-manager-before-upgrade-$(date +%Y%m%d-%H%M%S).tar.gz"
umask 077
if [ -f .env ]; then
  tar -czf "$backup_file" data .env
else
  tar -czf "$backup_file" data
fi
unzip -o /tmp/M3U-Studio-v0.3.4.zip -d /tmp/m3u-studio-update
cp -R /tmp/m3u-studio-update/m3u-studio/. .
sh setup.sh
docker compose up -d --build
```

若已有同名备份，请换一个备份文件名。浏览器刷新页面；升级后的网页登录使用原用户名和密码。全新安装则显示账号初始化页。后台订阅链接和列表 ID 保持不变。

## 编辑频道

- 管理多套独立列表；每套有固定订阅 ID，改名不改变订阅地址。
- 左侧频道列表与分组均可通过 `⠿` 拖拽调整顺序，电脑与手机均支持；“全部频道”固定在最前面。排序需要保存发布才持久化，列表顺序影响合并输出，分组顺序影响频道输出。
- 创建、重命名分组，删除空分组；导入 UTF-8 M3U/TXT（追加或替换当前列表）。
- 拖拽 `⠿` 到其他频道前后排序，拖到分组跨组移动；手机支持手柄触摸拖拽。已移除上下箭头。搜索时关闭排序拖拽，避免隐藏频道影响操作。
- 名称后显示分组标签；配置回放地址显示“回放”，配置 FCC 地址显示“FCC”。这些标签表示已配置地址，不代表已验证播放能力。
- 编辑名称、分组、Logo、直播、回放、FCC、回放类型/天数、EPG ID 和 EPG 地址。
- 搜索框与列表设置、导入和添加按钮位于同一排，节省频道空间。
- “设置”集中提供账号修改、配置备份和 JSON 恢复；“订阅与 EPG”保留独立入口。
- 顶部栏、左侧栏、频道工具栏固定；频道区域独立滚动。分组很多时，侧栏内部的列表区独立滚动，侧栏外壳保持固定。
- 修改先保留在当前页面内存中的草稿；刷新可能丢失未保存内容，点击“保存并发布”后订阅更新。页面退出会提示未保存修改；两页面并发修改会检测冲突。

## FCC

字段名称：**FCC（快速换台需使用rtp2httpd）**。

填写运营商 FCC 服务器 `IP:端口`，例如 `192.0.2.20:15970`，也接受 `udp://IP:端口` 或带 `fcc=` 的完整链接。导出 M3U/TXT 时自动将 FCC 写入频道直播 URL，例如：

```text
http://192.0.2.10:3224/rtp/239.125.2.1:4120?fcc=192.0.2.20:15970
```

现有其他查询参数保留，已有 `fcc=` 参数不会重复；导入 M3U/TXT 时会识别并拆分到 FCC 字段。清空此字段即可移除导出 URL 的 FCC 参数。`fcc-type=huawei` 等已有参数仍保留，可写在直播链接中。

填写原始 `rtp://`/`udp://` 组播地址时，会导出相同协议且附带 FCC 参数；需交由 rtp2httpd 的 M3U 转换功能处理后播放。本项目不内置 rtp2httpd，不负责运营商鉴权、接口配置或实际快速换台能力。

格式依据：[rtp2httpd 官方 FCC 文档](https://rtp2httpd.com/guide/fcc-setup)。

## Logo

支持 PNG/JPEG/WebP 上传，重新编码为 PNG，等比例缩小至 300×180 范围；不拉伸、裁剪或放大小图。上传请求上限 8MB、图片解码上限 1600 万像素。图片以原文件名保存为 PNG；覆盖同名台标必须明确选择替换。上传图片立即进入台标库，频道绑定在保存后发布。

公开版不内置电视台台标，请上传自己有权使用的图片。支持中文文件名和 `CCTV5+.png`；生成订阅时对中文路径进行 URL 编码。旧的 `HunanTV.png`、`CCTV5plus.png` 等英文地址通过别名映射继续可用，不在选择列表重复显示；旧台标需迁移到 data/logo 后继续使用。

`data/logo/` 中同名图片仍优先于内置图片，升级不会覆盖用户上传的 Logo。管理界面可删除台标；原有图片通过数据库隐藏记录保持升级后的删除状态，不修改镜像内资源。重新上传同名图片可恢复。旧版随机文件名图片仍保留并可选择；它们没有频道名称，因此不保证按名称自动匹配。

## 订阅、EPG 与回放

在列表设置中填写“订阅短名称”，保存并发布后可以用 `/lt.m3u`、`/yd.txt` 等短地址。支持 1–24 位字母、数字、下划线、短横线，以字母或数字开头，自动转为小写且不得重复。留空关闭短地址，修改后原短地址失效；固定 ID 长地址始终保留。

| 内容 | 路径 |
|---|---|
| 启用列表的合并订阅 | `/tv.m3u`、`/tv.txt` |
| 单列表订阅 | `/lists/固定ID/tv.m3u`、`/lists/固定ID/tv.txt` |
| Logo 示例 | `/logo/CCTV1.png` |

后台“订阅与 EPG”显示完整地址。独立订阅不受“加入合并订阅”开关影响。合并输出不去重频道，TXT 中相同分组聚合。

EPG 采用已有 XMLTV HTTP/HTTPS 地址；M3U 的 `x-tvg-url` 汇总全局、列表与频道 EPG，`tvg-id` 对应节目表。当前不下载 EPG、不生成本地 `/epg.xml`。

M3U 回放使用 `catchup`、`catchup-source`、`catchup-days`；TXT 回放保留第三列，不再追加第四列 FCC，FCC 放在第二列直播 URL 查询参数内。回放占位符、时间格式与第三列支持取决于服务端和播放器。TXT 不携带 Logo/EPG 元信息。名称、分组不得包含逗号；含逗号的播放 URL 建议使用 M3U。未知 M3U 扩展属性和注释不保留。

订阅按已保存的 SQLite 当前状态即时生成，不另写 output 文件。应用提供文件分发，不负责把 UDP 转 HTTP，继续填写 rtp2httpd 等服务的播放地址。

## 持久化与备份

`data/database/iptv.db` 保存配置及管理账号哈希，SQLite WAL 文件也属于完整数据；`data/logo/` 保存上传图片；`data/backup/` 保存最近 30 次成功发布前的配置 JSON。

“设置 → 导出配置备份”包含当前页面草稿，不包含密码、登录密钥和图片。恢复 JSON 先应用为草稿，再保存发布。跨设备恢复图片时需一并复制对应 Logo。

完整备份先停止容器再复制 data，避免遗漏 WAL。保留独立备份后再升级数据库；回退旧版本时恢复原 data。

管理后台使用网页会话登录；订阅和 Logo 无需登录。默认用于可信内网或 WireGuard；公网访问使用 HTTPS 反代并限制管理入口。
